# 交接

角色把结果交回总助，或总助把任务交给某个角色时，各写一份。17 不直接接收交接单，由总助转述需要 17 看的材料。

## 填写说明

文稿开头写三行：项目、日期、填写人。填写人是发出这份交接的角色。

| 字段 | 怎么写 |
| --- | --- |
| 从谁到谁 | 写「角色甲 → 角色乙」。交回时乙是总助。派工时甲是总助。 |
| 阶段 | 只写：立项、需求定义、方案设计、实现、MVP 演示、质检、最终验收、已收口。逆向拆解发生在需求定义之前时，阶段仍写「需求定义」，并在要对方做什么里标明「先拆解」。 |
| 附件 | 列出随附文件的路径或标题。没有文件时写对话里的材料名称，例如「17 提供的公开页面地址」。 |
| 要对方做什么 | 用祈使句写下一步，包含交回的产物和要停住的确认点。 |

一份交接只交一件事。下一阶段另写一份。

## 短示例

项目：内部读书会。日期：2026-10-29。填写人：客户经理。

- 从谁到谁：客户经理 → 总助。
- 阶段：需求定义。
- 附件：需求说明。
- 要对方做什么：请把需求说明呈交 17，等待「确认需求」。收到该回复之前，不要交给产品经理。

# 项目档案

总助维护。一个项目一份。真实项目放在该项目仓库中，本仓库的示例仅作示意。

## 填写说明

文稿开头写三行：项目、日期、填写人。日期写最近一次更新。

| 字段 | 怎么写 |
| --- | --- |
| 项目简介 | 一段话，说明给谁用、解决什么，以及明确不做的事。 |
| 仓库 | 写仓库地址。只有本地目录时写「本地项目」，绝对路径记在运行备忘，不写进档案。尚未创建仓库时写「尚未创建」。 |
| 当前阶段 | 只写：立项、需求定义、方案设计、实现、MVP 演示、质检、最终验收、已收口。 |
| 确认点记录 | 四个确认点各一行，写日期和 17 的原话。还没到的写「未到达」。 |
| 关键决策 | 每条写日期、问题、结论、对应待拍板文件。包含把某条验收标准改成「可随后再做」的决定。没有则写「无」。 |

当前阶段随流程前进。退回时，当前阶段改回对应确认点，确认点记录保留上一轮原话，并追加新的一行。

## 短示例

项目：内部读书会。日期：2026-10-29。填写人：总助。

- 项目简介：给同事报名周五读书会的内网页面，显示剩余名额。不做支付，不做账号。
- 仓库：尚未创建。
- 当前阶段：需求定义。
- 确认点记录：需求定义，2026-10-29，17 回复「确认需求」。方案设计，未到达。MVP 演示，未到达。最终验收，未到达。
- 关键决策：2026-10-29，名额上限，结论 12 人，见当次待拍板。

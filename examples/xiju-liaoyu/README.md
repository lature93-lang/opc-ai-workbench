# 戏剧疗愈小程序（示意）

这是一条脱敏的全链路样例，用来对照模板看「需求 → 方案 → 任务 → 演示 → 验收」怎么交回总助。人物只用角色称呼：17、学员、带领者。没有联系方式，没有密钥。

原项目仓库，不公开。写作时未能读取该仓库（远程返回无法访问）。下面的功能、页面和接口都按「戏剧疗愈小程序」这个主题编写，是示意，不是该仓库的摘录，也不能当作已经上线的记录。

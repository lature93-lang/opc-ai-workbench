# 任务

- 项目：戏剧疗愈小程序
- 日期：2026-09-08
- 填写人：产品经理

## 目标

未满员的场次可以提交显示名并占一个名额；剩余名额为 0 时不能提交。

## 输入

已确认方案的功能 3 和 4，以及任务「主题与场次」的详情页。报名不经过带领者审核，依据 [decision-signup.md](decision-signup.md)。

## 产出

详情页上的显示名输入框和报名按钮，以及创建报名的接口。成功时剩余名额减一。满员时按钮不可用并显示「名额已满」。

## 验收标准

对应需求验收标准第 3 条和第 4 条。用显示名「学员甲」提交一次，剩余名额减一。把剩余名额置为 0 后再试，提交被拒绝。

## 优先级

高。

## 负责角色

开发者。

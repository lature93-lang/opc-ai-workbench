# 任务

- 项目：戏剧疗愈小程序
- 日期：2026-09-08
- 填写人：产品经理

## 目标

学员打开小程序能看到至少两条主题，并进入一场场次详情，读到完整的非医疗声明。

## 输入

已确认的 [requirement.md](requirement.md) 与 [solution.md](solution.md)。仓库地址见 [project-profile.md](project-profile.md)。示意数据里预置两条主题，各下一场场次。

## 产出

主题列表页、场次详情页，以及主题和场次的读取接口。交回时附上 PR 链接。本样例不编造 PR 编号，开发交接里记为示意交付。

## 验收标准

对应需求验收标准第 1 条和第 2 条：能从列表进入详情，详情含完整声明。

## 优先级

高。

## 负责角色

开发者。

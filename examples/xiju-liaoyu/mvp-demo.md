## 范围

## 步骤

1. 打开小程序首页，确认能看到至少两条主题。
2. 进入其中一场详情，确认时间、剩余名额，以及完整声明「本小程序用于戏剧练习与情绪表达的报名，不提供医疗诊断，也不能代替带领者的现场工作。」
3. 剩余名额大于 0 时，显示名填写「学员甲」，点击「报名」，确认提示「已报名」，剩余名额减一。
4. 打开「我的报名」，确认该场状态为已报名。
5. 用一场剩余名额为 0 的场次，确认「报名」不可用，并显示「名额已满」。
6. 带领者打开该场名单，取消「学员甲」。学员再次打开「我的报名」，状态为已取消，该场剩余名额比取消前加一。

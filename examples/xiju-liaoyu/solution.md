# 方案

- 项目：戏剧疗愈小程序
- 日期：2026-09-08
- 填写人：产品经理

示意方案，对应已确认的需求说明。接口形状用于说明数据怎么走，不是远程仓库里的真实实现。

## 功能清单

1. 主题列表：展示至少两条主题。
2. 场次详情：展示时间、剩余名额、非医疗声明和报名。
3. 报名：未满员时填写显示名并占一个名额。
4. 满员拦截：剩余名额为 0 时不能报名。
5. 我的报名：学员看到状态为已报名或已取消。
6. 带领者取消：取消一条已报名记录，名额加回，学员侧变为已取消。

## 流程

1. 学员打开小程序，看到主题列表。
2. 学员进入一场场次，阅读声明，查看剩余名额。
3. 名额大于 0 时，学员填写显示名并提交。成功后剩余名额减一。
4. 学员打开「我的报名」，看到该场状态为已报名。
5. 带领者在该场名单中取消这一条。
6. 学员再次打开「我的报名」，状态为已取消；详情里的剩余名额加回。

## 页面/交互

主题列表页：入口是小程序首页。每条主题显示名称。点进主题后列出场次。没有主题时显示「暂时没有场次」。

场次详情页：从主题进入。显示时间、剩余名额和完整声明。报名区有显示名输入框和「报名」按钮。成功后按钮下方显示「已报名」。剩余名额为 0 时按钮不可用，并显示「名额已满」。

我的报名页：入口在首页。每条显示主题、场次时间和状态。状态只有已报名、已取消。

带领者名单页：从场次详情的带领者入口进入。名单显示显示名和状态。每条已报名记录有「取消报名」。取消成功后该行状态变为已取消。

## 数据与接口

对象主题：名称。对象场次：所属主题、时间、名额上限、剩余名额。对象报名：场次、显示名、状态。状态取已报名或已取消。不保存手机号和诊断信息。

读取主题与场次用列表和详情。学员提交报名用创建。带领者取消用一条只改状态的提交。学员读取自己的报名用按当前学员过滤的列表。示意路径：`GET /themes`、`GET /sessions/{id}`、`POST /signups`、`POST /signups/{id}/cancel`、`GET /me/signups`。

## 任务拆分

1. 主题与场次：列表和详情，含声明展示。负责角色：开发者。见 [task-theme-list.md](task-theme-list.md)。
2. 报名与名额：创建报名、减名额、满员拦截。负责角色：开发者。见 [task-signup.md](task-signup.md)。
3. 我的报名与取消：学员列表、带领者取消、名额加回。负责角色：开发者。见 [task-my-list.md](task-my-list.md)。
